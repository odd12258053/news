## 手順

### 1. 情報収集（WebSearch / WebFetch を使用）
以下の4分野それぞれについて複数回検索し、直近7日以内に公開されたものだけを集めてください。古い記事は除外します。検索クエリは英語で、年月を含めて「this week」「latest」などを加えると精度が上がります。

1. **モデル・研究動向**：新モデルの発表、主要な論文、ベンチマーク結果、OpenAI / Anthropic / Google DeepMind / Meta / Mistral / xAI / 中国系ラボ（DeepSeek, Alibaba Qwen など）の公式発表
2. **開発者向けツール・技術**：API・SDKの更新、エージェントフレームワーク、コーディング支援ツール、MCP、推論高速化、オープンソースの注目リポジトリ
3. **業界・ビジネス動向**：資金調達、M&A、提携、規制・政策（EU AI Act、米国・日本の動きなど）、主要企業の戦略発表
4. **活用事例・プロダクト**：新しいAIプロダクトのローンチ、企業や自治体での導入事例、実務で使える活用法

優先する情報源：各社公式ブログ、arXiv、The Verge、TechCrunch、The Information、Ars Technica、Hacker News で話題になった記事、GitHub Trending。SEO目的のまとめサイトや根拠の薄い噂は避けてください。
検索結果のスニペットだけで判断せず、重要な記事は WebFetch で本文を読んでから要約してください。

### 2. 選別
- 各分野につき 3〜5 件、合計 12〜18 件程度に絞る
- 「今週最も重要なニュース」を全体から 3 件選ぶ
- 同じ話題の重複記事は1つにまとめる

### 3. メール作成と送信
Gmail の送信ツール（mcp__Gmail__send_message）で、以下の形式で {{RECIPIENT_EMAIL}} に送信してください。本文は日本語、HTML形式で読みやすく整えてください。

- 件名：`【週刊AIダイジェスト】YYYY/MM/DD〜YYYY/MM/DD`（対象期間）
- 冒頭：**今週の注目トップ3** を各2〜3文で
- 続けて分野ごとのセクション（上記4分野の順）。各記事について：
  - 見出し（日本語）
  - 2〜3文の要約：何が発表され、なぜ重要か
  - 元記事へのリンク（必ず記載）
  - 公開日
- 末尾：**今週の一言所感**（全体を俯瞰して2〜3文）

要約は自分の言葉で書き、記事本文を長く引用しないでください。事実と推測は区別し、不確かな情報には「報道によれば」などを付けてください。

### 4. 完了報告
送信できたら、送信した件数と主なトピックを1〜2文で報告してください。Gmail送信が失敗した場合は、作成したダイジェスト本文をそのまま応答として出力し、失敗理由も添えてください。
