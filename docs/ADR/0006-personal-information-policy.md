# 0006. 個人情報の取り扱い方針

- 日付: 2026-09-30
- 状態: Accepted

## 背景
ADR 0003 で個人の値を `vars` に分離したが、その値自体を公開リポジトリに含めるかは未決定だった。
今後も routine の追加・変更に伴い、メールアドレス以外の個人情報（氏名、所属、他サービスの ID、
アカウント情報など）を含めるべきか判断する場面が出てくる。

## 決定
1. 現在 `vars.RECIPIENT_EMAIL` に設定しているメールアドレス（odd@agraffe.info）は、
   既に公開しているアドレスのため、公開リポジトリに含めてよい。
2. それ以外の個人情報にあたる値は、リポジトリに含める前に**必ず利用者に確認する**。
   Claude Code が自律的に含める判断をしてはならない。確認の結果は ADR または CHANGELOG に残す。

## 理由
- 本人が既に公開している情報まで隠すと、`vars` を gitignore する等の手間が増え、再現性も下がる。
- 一方で「何が公開済みか」は本人にしか分からないため、新しい値は都度確認するのが安全。

## 影響
- ADR 0003 の「未決定」は本 ADR で解消。`vars` は gitignore せず、そのままコミットする。
- CLAUDE.md の作業ルールに「個人情報は含める前に確認」を追加する。
- 確認が必要かどうか迷う値（例: 接続先の社内 URL、ハンドルネーム）は、迷ったら確認する側に倒す。
