# 0003. 個人の値を prompt から分離し vars で置換する

- 日付: 2026-09-30
- 状態: Accepted

## 背景
既存の prompt には送信先メールアドレスが直書きされていた。リポジトリを公開して他者に再利用してもらう以上、
prompt 本体は利用者固有の値を含まない形にしておきたい。

## 決定
prompt.md では利用者固有の値を `{{KEY}}` と書き、値は `routine.yaml` の `vars` に置く。
`scripts/render.py` が反映時に置換する。未定義の `{{KEY}}` があれば render は失敗させる。

## 理由
- 他者は prompt.md をそのままコピーし、`vars` だけ自分のものに書き換えれば使える。
- 置換をスクリプトで行うことで、書き換え忘れによる誤送信（他人のアドレスに送る等）を防げる。

## 影響
- `vars` の値をリポジトリに含めるかどうかは [ADR 0006](0006-personal-information-policy.md) で決定。
  現在のメールアドレスは公開済みのため含める。他の個人情報は含める前に確認する。
- connector の UUID や routine の ID も利用者ごとに異なるが、それ自体は秘密ではないため yaml に記載してよい。
